# 01 - React Basics – Vite Setup

A beginner-level React project created to understand the fundamentals of React and how a React application is structured using Vite.

## Concepts Practised

### 1. Setting Up React with Vite
- Creating a React application using Vite.
- Understanding the basic folder structure.
- Running a React development server.

### 2. Functional Components
- Creating components using JavaScript functions.
- Understanding how React components are structured.
- Creating separate component files.

### 3. JSX (JavaScript XML)
- Writing HTML-like syntax inside JavaScript.
- Understanding how JSX is used to describe UI elements.
- Returning JSX from React components.

### 4. Importing and Exporting Components
- Using `export default` to export components.
- Importing components into other files.
- Understanding how components can be organized across multiple files.

### 5. Rendering React Components
- Understanding `createRoot()` from `react-dom/client`.
- Selecting the root DOM element.
- Rendering the main App component inside the root element.

## Technologies Used

## Getting Started

Clone the repository or navigate to this project folder.

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Purpose

This project serves as an introduction to React, focusing on understanding its basic structure, components, JSX, and how React renders UI elements.
